# Учёт рабочего времени

Проект по ООП.

## Возможности

- Регистрация руководителей и сотрудников
- Команды (комнаты) с ключом и паролем
- Руководитель видит только свою команду
- Сотрудник видит только свои сессии
- Сохранение данных между запусками
- Отчёт при закрытии приложения (`report.txt`)


## Как пользоваться

### Первый запуск

Приложение пустое — сначала нужно зарегистрироваться.

### Регистрация руководителя

1. Нажми **«Зарегистрироваться»**.
2. Выбери роль **«Руководитель»**.
3. Заполни логин, пароль, название команды, пароль команды.
4. Нажми **«Зарегистрироваться»**.
5. Появится окно с ключом команды (например, `A3F91B`) — **сохрани его**.
6. Передай ключ и пароль команды сотрудникам.

### Регистрация сотрудника

1. Нажми **«Зарегистрироваться»**.
2. Выбери роль **«Сотрудник»**.
3. Заполни логин, пароль, **ключ команды**, **пароль команды**.
4. Нажми **«Зарегистрироваться»** — после этого можно войти.

### Работа

- **Сотрудник**: кнопки «Вход» и «Выход» открывают и закрывают его сессию. Видит только свои записи.
- **Руководитель**: видит все сессии своей команды, но не может открывать или закрывать их. Также может фильтровать по сотрудникам и по статусу «на смене / завершена».

### Выход из аккаунта

Кнопка **«Выйти из аккаунта»** в правом верхнем углу. Данные сохраняются.

## Файлы

| Файл          | Что содержит                                    |
|---------------|-------------------------------------------------|
| `data.txt`    | Пользователи, команды, сессии (создаётся сам)  |
| `report.txt`  | Отчёт при закрытии приложения (создаётся сам)  |

## Про пароли

Пароли хранятся открытым текстом.

entities/ — сущности (User, Team, WorkSession)

storage/ — CustomMap, репозиторий, сохранение в файл

ui/ — окна и кастомные виджеты

main.py — точка входа
